Graphical Authentication Password System

Timeline: Feb 2025 - Mar 2025

A novel cybersecurity project leveraging machine learning to authenticate identity using graphical layouts and interaction dynamics instead of textual passwords.

Key System Features:

  • Pattern-Based Interaction: Bypasses standard textual passwords, utilizing visual touch shapes and coordinates.
  • Behavioral Telemetry (AI/ML): Uses Python models to inspect touch pressure, coordinate intervals, stroke speeds, and rhythms.
  • High-Confidence Verification: Employs machine learning classifiers to distinguish genuine touch signatures from imitation patterns, significantly reducing replay attacks.
  • Dynamic Graphic Interface: Easy-to-use canvas interface mapping mouse/touch drags into real-time telemetry inputs.

Technical Architecture:

Engineered using Python, utilizing SciPy / NumPy for math calculations, Tkinter / Matplotlib for user canvas capture, and simple ML classifiers for behavioral dynamics classification.
